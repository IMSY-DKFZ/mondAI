# Installation

To install `mondAI` from PyPI run
> pip install mondAI

To install it from gitlab, run
> pip install git+https://gitlab.com/dkfz_imsy/mondai.git

To install the development version, clone the repository and run
> git clone https://gitlab.com/dkfz_imsy/mondai.git
> cd mondai
> pip install -e .[dev]
