# mondAI

This package provides image quality metric implementations which are:
* correct (in the sense of the original definition)
* usable
* reproducible and reportable
* tested
* documented


## Installation

To install `mondAI` from PyPI run (not working yet)
> pip install mondAI

To install it from gitlab, run
> pip install git+https://gitlab.com/dkfz_imsy/mondai.git

To install the development version, clone the repository and run
```bash
git clone https://gitlab.com/dkfz_imsy/mondai.git
cd mondai
pip install -e .[dev,comparison]
```
